# Data

This project uses the **Real / Fake Job Posting Prediction** dataset.

## Download

1. Open [Kaggle: Real or Fake Fake JobPosting Prediction](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction).
2. Download `fake_job_posting.csv`.
3. Place the file here as:

   `data/raw/fake_job_postings.csv`

If you already have a copy named `DataSet.csv` (as in the original notebook), you may place it at `data/raw/DataSet.csv` instead.

## Notes

- CSV files under `data/raw/` are gitignored to keep the repository small.
- Do not commit datasets that include personal or proprietary information.
